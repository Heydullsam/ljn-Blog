LCR 177 撞色搭配

发表于 2026-07-10 更新于 2026-07-11 分类于 位运算

Problem: LCR 177. 撞色搭配

思路

由于其他数字都成对，我们进行异或和最终两两相消，得到的是结果的两数的异或值，现在问题是怎么把它分开得到两个数。注意到异或结果不可能为0（两数不相等），则二进制位中1的地方，正好结果对应的两个数的对应位置是1和0。以此为基准，我们又可以把sockets分为两组（该位为1或该位为0），进而再次异或，依旧两两相消，最后的结果一定是要找的两个数

解题过程

使用库函数reduce快速得到异或和，i&-i是常见的取二进制最低位的方法（树状数组常用）。a,b记录每个分组的异或和，即可解决问题

复杂度

  • 时间复杂度: $O(n)$
  • 空间复杂度: $O(1)$

Problem: 3093. 最长公共后缀查询

思路

排序加字典树可以简化题目中的要求

解题过程

按照(长度,出现时间)进行排序,并把排序后的每一个词语加入字典树,同时在第一次创建该树节点的时候填写val(字典树走到此处时哪一个点是结果).因为填写的顺序,使得每一个节点的数字正好是访问的答案,后续进行访问即可.

复杂度

  • 时间复杂度: $O(nlog(n))$排序建树查询均是nlog(n)
  • 空间复杂度: $O(n*m)$最多每一个字母分配一个trie,但是实际上son只有26,结果会小很多

Problem: 29. 两数相除

思路

除法本质上就是减法,现在问题就是怎么让它减的更快,10进制时我们执行120/12时,会将12对齐,实际效果就是除数乘10,但是现在不允许我们使用乘法,我们改用位运算进行模拟乘法来试商.

解题过程

简化问题,我们直接处理正数除正数后续再处理符号和溢出问题.我们用res记录当前乘积的倍数(1,2,4,8)同十进制的(1,10,100,1000),然后从高位开始减,能减时就减去并给ans+=res(类似试商后减少剩余被除数),直到res==0,即除到最后一位

复杂度

  • 时间复杂度: $O(1)$最多32位,循环就最多32次,为常数
  • 空间复杂度: $O(1)$

127 单词接龙

发表于 2026-06-04 更新于 2026-07-11 分类于 广度优先搜索

Problem: 127. 单词接龙

思路

bfs每次从wordList中枚举的话最多2500次出队*2500次遍历，每次遍历还要比较单词的差异数，太慢了，注意到访问过的点我们不会再访问（bfs已经找到更近的点），那我们就跳过这些点的访问，但是仅仅跳过，仍要比较差异数。既然我们已经知道哪些点是还未访问的，如果他们在哈希表中，我们就不用遍历单词数次数了2500，因为单词很短的缘故，我们枚举单个字符的修改是否在hash表中，则最多需要26*len(word)=260次运算。

解题过程

先把wordList放入hash表中，访问过的逐个移除，单个字符修改上，我们循环26次+1并取模，前25次相当于完成修改，最后一次相当于还原。然后是我常用的bfs写法

复杂度

  • 时间复杂度: $O(NM26)$N为len(wordList),M为len(beginWord)
  • 空间复杂度: $O(N*M)$hash表+队列大小之和
