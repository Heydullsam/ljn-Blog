173 二叉搜索树迭代器

发表于 2026-06-03 更新于 2026-07-11 分类于 栈

Problem: 173. 二叉搜索树迭代器

思路

要求O(h)内存，说明不能存储遍历过的节点，我们使用栈来进行中序遍历。

解题过程

注意到每个节点的遍历顺序是左根右，因此我们在访问一个节点时，先递归把它的左节点以及子树的左节点压栈。出栈代表已经访问，此时单独把它的右子树入栈。
由于第一次遍历是第一个节点，我们格外用一个dummy节点表示起点

复杂度

  • 时间复杂度: 均摊$O(1)$每个节点入栈出栈一次
  • 空间复杂度: $O(h)$栈最高为树高

134 加油站

发表于 2026-06-01 更新于 2026-07-11 分类于 贪心

Problem: 134. 加油站

思路

问题转换，数组正向移动满一圈，每次油量res加gas[i]-cost[i],存在res<0则说明这个起点不行，遍历每一个起点，时间复杂度$O(n^2)$,会超时。
优化方式：每次起点从上一次res<0的点开始，并保证起点res>=0(否则没法启动)，设起点x（x>0）,容易得到x+中间=res<0,中间部分加到res位置时一定会小于0，可以排除

解题过程

方便计算，使用diff直接记录gas-cost,另外开始点的停止条件为遍历完一圈。每次遍历时发现可以满足就直接返回True

复杂度

  • 时间复杂度: $O(n)$start和循环单圈遍历次数和不会超过2*n，n为数组长度
  • 空间复杂度: $O(n)$ diff长度，省略可以$O(1)$

Problem: 151. 反转字符串中的单词

思路

已知cpp std::reverse是原地交换，这里我们可以用时间换空间，先把整体反转，如hello world反转成dlrow olleh,然后我们很容易发现，把每个空格分割段再局部每一处调用一遍reverse，就可以得到world hello了，然后关键是多余空格的处理。这里我直接过滤前导空格，然后用pos记录当前写入字符串的位置，后续直接使用resize对字符串进行截断即可

解题过程

细节上，正向过滤后在，反转复用来过滤后面的空格（直接判断末尾是不是空格再截取更方便，因为末尾最多有一个空格），遍历s时，注意到末尾还要进行一次处理，故循环条件设置为i<=s.size().注意函数使用值引用传参（无拷贝）

复杂度

  • 时间复杂度: $O(n)$
  • 空间复杂度: $O(1)$

220 存在重复元素 III

发表于 2026-03-16 更新于 2026-07-11 分类于 数组

Problem: 220. 存在重复元素 III

思路

根据题意可知：我们需要寻找区间内的两个数，使之差小于指定值，如果区间是有序的，我们选定一个值，我们等同于区寻找第一个大于等于和第一个小于它的数，可以使用二分解决

解题过程

我们使用滑动窗口来保证是区间内的两个数在比较，每次加入新的数后，如果区间大于要求区间，我们删除区间最左边的元素，每次遍历时，二分寻找需要的两个值来分别与之做差，如果满足两者之差小于等于valueDiff,则返回true,否则返回false

复杂度

  • 时间复杂度: $O(n*logn)$
  • 空间复杂度: $O(n)$
