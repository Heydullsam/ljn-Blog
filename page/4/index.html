1026 节点与其祖先之间的最大差值

发表于 2025-11-19 更新于 2026-07-11 分类于 树

Problem: 1026. 节点与其祖先之间的最大差值

思路

递归

解题过程

思考每一个节点，它可以为下一层更新最大值和最小值，同时它可以更新结果值，
而它的子节点同理。对于每个节点的结果，应该是$max（自己更新值，左节点更新值，右节点更新值）$,上一层节点在“归”时可以根据其子节点更新，最终root的结果即是答案

复杂度

  • 时间复杂度: $O(n)$
  • 空间复杂度: $O(n)$

思路

解题过程

以层数确定结果的下标，当层数>=ans.size()时，说明下标已经超出数组大小了，需要扩容（直接push_back）,否则更新ans[level]的值，使其是最新的（最后遍历到的）

复杂度

  • 时间复杂度: $O(n)$
  • 空间复杂度: $O(n)$

139 单词拆分

发表于 2025-11-12 更新于 2026-07-11 分类于 字典树

Problem: 139. 单词拆分

思路

考虑到达到（dp[i]=1）当前状态时，能到达的状态设为dp[i+1]=1,而怎么查看能达到的目的地呢，我们通过字典树从根节点进行遍历，根据s为前缀能达到的所有end=1的情况就是能达到的状态

解题过程

字典树，dp创建，定义搜索函数（用于寻找当前状态能达到的所有状态），然后正向遍历即可，dp[n]即是结果。

复杂度

  • 时间复杂度: $O(N^2)$
  • 空间复杂度: $O(N+K)$
