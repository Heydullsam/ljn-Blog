Problem: 2429. 最小异或

思路

暴力枚举最小值，即x XOR num1的最小值是我们需要求的，然后要求x置位数为指定值即可，怎么得到x，(x^num1)^num1=x,即我们再吧枚举的最小值^num1就可以找到对应的x；

解题过程

可以使用现代cpp的find_if进行惰性加载枚举的值

复杂度

  • 时间复杂度: $O(*)$
  • 空间复杂度: $O(*)$

2402 会议室 III

发表于 2025-12-27 更新于 2026-07-11 分类于 数组

Problem: 2402. 会议室 III

思路

起初我只使用了一个堆，每次遍历时插入<max(finish,start)+end-start,id>,就是说每次把会议放在结束时间最早的房间，但是引发了一个问题，在一个时间点（start=4），room[2]结束时间可能是1，room[1]为2，此时它们都已经结束了，因而需要选择编号小的1而不是2。也就是说，已经结束的需要单独拿出最小的编号进行处理，考虑使用第二个堆维护【已经结束的编号最小的堆】

解题过程

先排序,保证start递增，然后遍历。遍历时，先将【所有已经结束】的从pq取出，放入out中。然后检查out，存在编号就直接取最小编号出来，注意到开始时间正是start，我们把<finish,id>放入pq; 不存在时，我们认为start应为pq中最早结束的，取pq.top(),放回<finish_origin+时间间隔（finish-start）,id>,此外注意加法可能溢出，使用long long。最终结果就是room记录次数中次数最大编号最小的

复杂度

  • 时间复杂度: $O(Nlogn)$
  • 空间复杂度: $O(n)$

329 矩阵中的最长递增路径

发表于 2025-12-23 更新于 2026-07-11 分类于 深度优先搜索

Problem: 329. 矩阵中的最长递增路径

思路

先考虑到暴力解法，从每一个格子开始遍历，只向比自己大的方向dfs，可以直接维护一个变量level来记录最大深度
循环200*200，dfs 200*200
运算$1.6\times 10^9$次，显然会超时
但是考虑到每个点在计算出其最大深度时，下一次从别的点开始到达这个点时，就不用再次计算了，我们用一个cache来记录i，j位置上已经计算出的最大深度

解题过程

直接考虑“归”的过程，我们只关心每一次返回计算次数向上传递，不用再记录level，返回值直接返回最大深度。具体的，对于i，j,我们先看cache中有没有存储，如果没有，自己本身深度res设置为1，考虑其他方向的深度时，为dfs(xx,yy)+1,res只记录之中的最大值就行

复杂度

  • 时间复杂度: $O(n*m)$,每个位置最多计算一次
  • 空间复杂度: $O(n*m)$,cache空间

Problem: 100841. 使子字符串变交替的最少删除次数

思路

统计发生不同（和上一个不同）的值，区间-不同=修改数，注意第一个一定不用修改，故从l+1开始

解题过程

+=i&(-i),-=i&(-i)好记，我就这么写了，其他就是线段树的模板，
修改时我们发现它和前一个相同，那么修改后它及以后的值都会+1，否则-1；
同理，如果它后后一个相同，那么修改后它后一个以以后都会+1,否则-1；

复杂度

  • 时间复杂度: $O(Nlogn)$
  • 空间复杂度: $O(n)$

  • 空间复杂度: $O(n+m)$不考虑已经有的空间
