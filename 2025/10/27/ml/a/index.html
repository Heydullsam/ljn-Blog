3 linear regression

Training: Data used to train the model
x = "input" variable feature
y = "output" variable/ "target" vatiable
m = number of training examples

$$(x^{(i)},y^{(i)})=i^{th}\ training\ examples$$
$$Model：f_{w,b}(x)=wx+b,(w,b\ named\ parameters\ or \ coefficients\ or\ weights)$$
[^1]
$$Cost\ function:\ J(w,b)=\frac{1}{2m}\sum_{i=1}^{m}(\hat y^{(i)}-y^{(i)})^2=\frac{1}{2m}\sum_{i=1}^{m}(f_{(w,b)}(x^{(i)})-y^{(i)})^2$$

3.1 Gradient descent algorithm

$$w=w-\alpha\frac{\partial}{\partial w}J(w,b)=w-\alpha\frac{d}{dw}J(w),\ \alpha \ is\ learning\ rate$$
$$b=b-\alpha\frac{\partial}{\partial b}J(w,b)$$

Near a local minimum,

  • derivative becomes smaller
  • update steps become smaller
    Can reach minimum without decreasing learning rate

repeat until convergence:
$$w=w-\frac{1}{m}\sum_{i=1}^{m}(f_{w,b}(x^{(i)})-y^{(i)})x^{(i)}$$
$$b=b-\frac{1}{m}\sum_{i=1}^{m}(f_{w,b}(x^{(i)})-y^{(i)})$$

3.2 “Batch” gradient descent

Each step of gradient descent uses all the training examples

3.3 mutiple linear regression

$$f_{\vec w,b}=\vec w·\vec x+b=w_1x_1+w_2x_2+w_3x_3\cdots$$

Gradient descent:
repeat:
$$w=w-\alpha\frac{\partial}{\partial w_j}J(\vec w,b)$$
$$b=b-\alpha\frac{\partial}{\partial b}J(\vec w,b)$$

4 An alternative to gradient descent

4.1 Normal equation

  • Only for linear regression
  • Solve for w,b without itertions

4.2 Disadvantages

  • Doesn’t generalize to other learning algorithm
  • Slow when number of features is large(>10000)

5 normalization

5.1 Feature scaling

eg $x_1<2000,x_{1,scaled}=\frac{x_1}{2000}$

5.2 Mean normalization

[^2]
eg $300\le x_1\le 2000,x_1=\frac{x_1-u_1}{2000-300}$

5.3 Z-score normalization

[^3]
eg $x_1=\frac{x_1-u_1}{\sigma _1}$

5.4 skills

make values of $\alpha$ to be 3 times of itself
eg 0.001, 0.003, 0.01, 0.03

6 Feature engineering

Using intuition to design new features, by transforming or combining original feature
eg $x_3=x_1*x_2$

7 Polynomial regression

$$f_{\vec w,b}(x)=w_1x+w_2x^2+b$$
feature scaling: eg add x^3 to avoid the line from go dowm

8 Classification

“binary classification”

8.1 logistic regression

sigmoid funtion:outputs between 0 and 1
$$g(x)=\frac{1}{1+e^{-x}},0<g(x)<1$$
$$f_{\vec w,b}(\vec x)=g(\vec w ·\vec x+b)=\frac{1}{1+e^{-\vec w·\vec x+b}}$$

8.2 Decision Boundary

eg. $z=x_1+x_2-3$, easy to get $x_1+x_2=3$

8.3 Non-linear decision boundaries

eg. $z=x_1^2+x_2^2-1$

8.4 Cost

$$J(\vec w,b)=\frac{1}{m}\sum_{i=1}^{m}L(f_{\vec w,b}(\vec x^{(i)},y^{(i)})=\begin{cases}-log(f_{\vec w,b}(\vec x^{(i)})),if\ y^{(i)}=1\-log(1-f_{\vec w,b}(\vec x^{(i)},if\ y^{(i)}=0))\end{cases}$$

8.5 Gradient descent for logistic regression

[^4]
$$w_j=w_j-\alpha[\frac{1}{m}\sum_{i=1}^{m}(f_{\vec w,b}(\vec x^{(i)})-y^{(i)})x_j^{(i)}]$$
$$b=b-\alpha[\frac{1}{m}\sum_{i=1}^{m}(f_{\vec w,b}(\vec x^{(i)})-y^{(i)})]$$
Regularition

underfit, 
just right,
 overfit, Collect more training examples; select features to include/exclude, Regularition(Reduce the size of parameters w_j)
