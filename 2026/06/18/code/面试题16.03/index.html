Problem: 面试题 16.03. 交点

思路

通过求出每一条直线的方程y=kx+b,进而求出交点$(x=\frac{b_1-b_2}{k_2-k_1},y=x*k_1+b_1)$.最后再判断点是不是在两条直线上

解题过程

需要特判直线垂直于x轴的情况

复杂度

  • 时间复杂度: $O(1)$
  • 空间复杂度: $O(1)$
