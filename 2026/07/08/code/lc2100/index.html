Problem: 2100. 适合野炊的日子

发表于 2026-07-08 分类于 前后缀分离

思路

使用pre记录到当前位置时左边连续大于自身右边的数目,suf记录当前位置时右边连续大于自身左边的数目,当两者都>=time时,将其加入答案

解题过程

time==0时答案为整个数组的下标,pre数组可以用一个变量替代

复杂度

时间复杂度: O(n),两次遍历就可以解决问题
空间复杂度: O(n),suf的空间
